## Which file do I need?

| You want to | Download |
| --- | --- |
| Install ModelVault on Windows | **ModelVault-…-Setup.exe** |
| Run it on Windows without installing | **ModelVault-…-windows-x64.zip** |
| Run it on a NAS or with Docker | **Source code (zip)**, then follow the [setup guide](https://github.com/R3nierjvr/ModelVault#synology-nas-container-manager) |

**Already using ModelVault?** Open **Settings > About** and choose **Download and install**: it picks the right file by itself and keeps your data. On Windows you can also just run the new installer over your current install. (**ModelVault-…-app.zip** is the file the updater uses for NAS and Docker installs.)

The Windows downloads include their own Node.js and 7-Zip, so there's nothing else to install. ModelVault opens in your browser at http://localhost:8420.

**First run on Windows:** the installer isn't digitally signed yet, so SmartScreen warns you. Choose **More info**, then **Run anyway**. If Windows Firewall asks about Node.js, allow **Private networks** to use ModelVault from your phone or tablet too.

### What ModelVault does
- **Models:** your 3D print library with 3D previews, importing from archives, duplicate checks, paste-a-picture covers and folder naming you choose
- **Import an existing library:** restore a ModelVault backup, or bring in Orynt3D, Manyfold, Thingiverse downloads or any folder
- **Backup:** with or without model files, downloaded or saved to a folder
- **Paints:** about 6,000 paints from 10+ brands, matches between brands, a palette from any picture, paint schemes, racks and a shopping list
- **Materials:** 6,383 filaments and 309 resins, colour and multi-colour search, spool tracking, and a check of what your printers can print
- **Tools:** about 600 printers to pick from, plus airbrushes, brushes and more, with service reminders and history
