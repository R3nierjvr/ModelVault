      Archive names

      Name each model's ZIP, 7Z and RAR files by what's in them, such as the bust, an X-pose or the scale. You can also set the part and scale for each archive on a model's page with "Name archives".

      PartsThe label used in the name, and the words in an archive's name that mean it, separated by commas. Checked from the top. An archive with only pictures inside gets the part whose words include "images".

        Where is your library coming from?

        Restore a ModelVault backup

        Bring your models, categories, tags, paints, materials, tools and settings over from a backup, for example after moving ModelVault to another PC or NAS. Make one under Settings > Backup on the old install. On Windows, the library folder changes to the backup's library (a NAS share, say), so the models open from where they are. What's in ModelVault now is kept aside, so nothing is lost.

        Folders on this PC

        Add any folder ModelVault should see: on this PC, on a mapped drive (like M:) or on a shared folder. Pick it in the folder browser.

          Network folders
